# Tekstein LLC Landing Page

The public marketing site for Tekstein LLC, maintained separately from Tekstein Workforce.

## Local development

```sh
npm install
npm run dev
```

## Replit

Import this repository into Replit to preview and iterate on the design. Keep changes on a feature branch or review pull request so the production landing page stays reviewable.

## Brand and experience

The site uses Tekstein's official navy, maroon, and white identity, with original page structure and copy. It takes inspiration from polished infrastructure-services sites without reusing their branding, claims, or assets.

## Domain routing

The intended public routes are:

- `/` — Tekstein LLC landing page
- `/workforce/` — Tekstein Workforce

The landing source is intentionally separate. Production routing still needs to send both routes through the same public host.
